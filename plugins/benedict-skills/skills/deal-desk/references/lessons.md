# Lessons log: what every build must get right

Read this **before every model or deck build**. After every case (a live case, a Case Gym round, Benedict's critique or a post-test review), add the new lessons here. If a lesson can be checked by code, add it to `xlstyle.py` / `model_lint.py` / the generators **in the same session**, and bump `STYLE_VERSION` in `xlstyle.py`.

Current house style: **v2.1** (26 Sep 2026). Worked examples: `Interview Prep/Case Studies/_Worked examples/` (see `V2 Changelog.md`).

## How to add a lesson
1. Add a row: rule (imperative, specific) · why · source (who / what file / URL) · date · enforced by.
2. Automate it if possible; otherwise add it to `qa-checklist.md`.
3. Rebuild the worked examples (`build_lbo.py`, `build_pf.py`) and confirm lint = 0 and verify = OK.
4. If the change is visible to Benedict, add a line to `Interview Prep/Case Studies/_Worked examples/V2 Changelog.md` (or start a V3 changelog).
