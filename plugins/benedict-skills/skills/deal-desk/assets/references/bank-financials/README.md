# Bank financials on slides: reference pages

Real bank board books filed with the SEC. These are the format behind `ibdeck.fin_table()` and `ibdeck.fin_chart()` (lessons.md row 28). Look at these before building a financials slide.

| File | Source | What to copy |
|---|---|---|
| `goldman-p20-summary-table.jpg` | Goldman Sachs, Focus Financial board materials, Nov 2022, p.20 ([SEC](https://www.sec.gov/Archives/edgar/data/1651052/000110465923049226/tm2313164d1_ex99-c1.htm)) | Units in the subtitle; periods with A/E; header row unfilled with a navy rule; key lines bold with "$" (their band fill is not copied); italic indented "% Growth" / "% Margin" rows |
| `goldman-p23-full-projections.jpg` | same deck, p.23 | Full projections page: same rules at full size |
| `goldman-p16-trend-charts.jpg` | same deck, p.16 | Bars with values on top; CAGR arrows; dashed actual/forecast split; % growth strip under the bars |
| `evercore-p34-charts-with-strips.jpg` | Evercore, Diversey special committee, Mar 2023, p.34 ([SEC](https://www.sec.gov/Archives/edgar/data/1831617/000110465923043816/tm2311114d1_ex99-ciii.htm)) | Three trend charts side by side, CAGR boxes, "(All financials in $mm unless otherwise stated)" note, small % YoY table under each chart |
| `evercore-p22-side-by-side.jpg` | same deck, p.22 | Revenue / GP / EBITDA mini charts with margin % labels |

What we don't copy: Goldman's yellow row highlight (every row stays white) and Evercore's multi-colour series (navy ramp only, per house style).
